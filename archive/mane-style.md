# Mane Style Guide

Mane is a format alternative to Markdown. It's goal is to extent and simplify Markdown to support more long form writing.

## Paragraphs

Paragraphs are handled as they appear. Unlike Markdown Mane treats all new lines as new lines.

## Indents

Indents work from 1 to 4.
