Sorry it took over a month for me to write this blog. I got distracted working on FixFiction. Which speaking of, is getting a 2.1 update soon! It's been live for a week or two, I just need to write the blog post for it after finishing some behind the scenes code for logging errors.

As for this story, it was the first version of the April Fools story. I ended up re-writing it and released that version while I was banned for the day. I was trying to write a somewhat meta story about Pinkie being banned from Twilight's library, but both times It turned out better without that aspect in the story.

I know I say this every time, but I liked how this story turned out, it's cute. I realize that if I didn't like it, I probably wouldn't have released it. I love Twilight x Pinkie, it's my favorite ship, so no surprise I wrote another one. I do want to write more ships, so that's what I'm going to do.

My last two comments on my user profile have asked for more Rarity and Pinkie romance, and that's what I'm going to write next. I already have an idea for it, and I'm excited to get back to writing. After that story, I will get to work on the first story for the [giveaway](https://www.fimfiction.net/blog/1130131/200-followers-giveaway-winners-announcement), which is for [marmalado](https://www.fimfiction.net/user/362455/marmalado).

I feel like I'm running out of ideas for covers using the pixel art pony sprites I've been using for a while now. There's only so many ways to arrange them on a cover. I don't know what I'll do in the future, so if you have any ideas, feel free to voice them in the comments.

Also, in my [blog](https://www.fimfiction.net/blog/1127694/a-letter-of-little-to-no-significance) for [A Letter of Little to no Significance](https://www.fimfiction.net/story/580171/a-letter-of-little-to-no-significance) I mentioned two people who have helped me on recent stories. My goals this month are to get the code and blog done for FixFiction 2.1. And to release two stories. We'll see how it goes. Thanks for reading!
