# Sorrows of the Sleeping

Tagged story: [Sorrows of the Sleeping](https://www.fimfiction.net/story/586392/sorrows-of-the-sleeping)

***

This was the last of the three stories I wrote for [Jinglemas](https://www.fimfiction.net/group/213263/jinglemas) 2025. I had written two stories for the pony I got. So, why not make it so a Breezie recipient also got two stories?

This was the first time I've written Fluttershy x Applejack, and it was fun! I wrote it as Equestria Girls since my idea for it was inspired by my story, [Whispers and Wishes](https://www.fimfiction.net/story/560940/whispers-and-wishes).

The prompt I got was:
> I'd like it to feature Fluttershy and Applejack, and it would be great if it was a Flutterjack shipfic. EqG or Original flavor are both fine by me.

I wanted to get this blog out sooner, but got busy with coding on that secret project I mentioned before. It's going good, it's up to the same number of lines of code as FixFiction at this point.

Hopefully my next blog won't take as long to get out. See you next time!
