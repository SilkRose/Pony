Now, let's get into the feature ideas!

Before any new feature is added, we are going through and cleaning up the project and its code. We want to make future development easier and more sustainable, and make it easier for new contributors to join in.

This include stuff like adding code comments, refactoring code to be more idiomatic, writing tests and using containers, to name a few.

There are currently two know bugs in the embed code, these will likely be fixed during the process mentioned above.
1. Fix story embeds so /stats endpoint works.
2. Fix fragment conversion for `#page/1` on user profile and story pages.

Probably the first new feature to be added will be a Fimfiction status page. It would tell you the current status of Fimfiction, and the history of its availability. [knighty](https://www.fimfiction.net/user/1/knighty) has even given his approval of this feature being made (but not an endorsement).

We'll probably also make a FixFiction status page, but that likely won't be hosted alongside FixFiction itself.

After the status page is done, we plan to archive all the stories on the site. I know other projects try and do this, but they either don't run frequently enough and miss stories that get deleted, or are incomplete due to *reasons*…

We also want to archive all blogs from the site as well.

The mane (heh) goal of archiving all the stories and blogs is better search and discovery.

We want to have full text search over all the stories and blogs on the site. So many times I see people trying to find a story and only being able to remember a line or two. With this you have a chance of finding it without having to rely on the memory of other users.

Alongside this, at a later point we want to add a daily story per genre list that can take a bookshelf and try and find similar stories for you to read.

Along with archiving all the stories and blogs, we want to archive all the images in those stories and blogs, all the covers, and all the user profile pictures. Online storage isn't free, so this is another reason we need donations.

A feature I think a lot of people would like is cover and profile picture links that always return the latest version, so they never break in embeds/site posts.

Another big feature is free image hosting for all writers. We want to give every writer free image hosting for chapter images based on how many words and stories they've published. This would increase with donations too.

We have a lot of ideas for improving the writing and proofreading experience as well.

We want to allow writers to manage their stories on FixFiction. We want them to be able to grant editing access to their editors and proofreaders. They can approve a change and the story will update on Fimfiction automatically.

We have big plans for a community proofreading system, where you can submit your story for proofreading and someone can decide to proofread it.

A lot of this would tie into a custom tag blacklist system, so any tags or keywords found in the description would hide a story so you don't have to see whatever you don't want to.

We want to offer full histories for any story edited through FixFiction, plus the ability to rollback to any state.

Probably the biggest feature we want is collaborative writing like on Google Docs.

We want authors to be able to host their outlines and story notes in the same place they write their stories, with the ability to grant access to anyone or even make it pubic to their readers.

We want to enable timed automatic story updates, so you can publish a story or chapter whenever you want. These will have the ability to change or update the description at the same time.

We have even more ideas than this. To see them all and suggest your own, join our [Discord](https://discord.gg/vUH8HYjC6V).

Thank you to anyone who donates or even just takes the time to read this.
